# Elite

App web simple para desarrollo personal masculino con un **tracker de hábitos diarios**.

## Incluye

- Registro de hábitos personalizados.
- Marcado diario de cumplimiento.
- Rachas por hábito.
- Estadísticas rápidas del día (hábitos activos, completados y progreso).
- Persistencia local en el navegador (LocalStorage).

## Uso

1. Abre `index.html` en tu navegador.
2. Agrega hábitos con el formulario.
3. Marca cada hábito cuando lo completes.
4. Usa "Reiniciar día" para desmarcar hábitos al comenzar una nueva jornada.
